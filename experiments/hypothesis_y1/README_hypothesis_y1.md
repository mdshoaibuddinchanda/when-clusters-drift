Phase-7 falsification experiment. It does not replace or modify the historical
Phase-7 record. All analyses here are exploratory or methodological corrections
unless explicitly identified as an independent reproduction of the frozen
protocol.

Required runtime: the existing Conda interpreter at `D:\Conda\p12\python.exe`.
No environment creation or dependency installation is permitted for this audit.

Branch: `hypothesis-y1-master-audit`.
